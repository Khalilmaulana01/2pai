**Pemantauan penerapan CPOB di area produksi** 
-> pemantauan rutin, lakukan inspeksi lapanagan tanpa pemberitahuan terjadwal (mis. area produksi)
1. personil -> operator menggunakan APD dengan benar dan lengkap sesuai protab
2. Ruangan & peralatan -> status 'bersih' pada label peralatan, tekanan udaranya sesuai standar 
3. dokumentasi -> ngelihat operator melakukan pencatatan di BMR (batch record) secara 'real time', bukan menunda hingga akhir shift, kalo misalnya mereka lupa, saya akan ngingatin untuk dilengkapi

**Menyusun atau merevisi sebuah Prosedur tetap (protab)**
1. Pilih satu protab -> (penanganan penyimpanan, line clearance)
2. cari tahu, alasannya pembuatan/revisi -> peratuhan baru, temuan audit
3. langkah
	1. buat draf
	2. diskusi dengan lintas departemen (qa, qc, produksi, teknik)
	3. finalisasi
	4. proses persetujuan (ttd)
	5. sosialisasi
-> pernah ada audit di kimia farma soal line clearance, temuannya soal pintu pengemasan yang bisa dibuka oleh siapa saja dan bisa dari dalam keluar, sehingga jadi temuan -> didokumentasikan -> cek di CPOB -> CAPA -> revisi -> TTD QA -> sosialisasi

**Audit internal & CAPA** (audit major terkait validasi pembersihan)
1. pelaporan -> dokumentasi dalam laporan audit 
2. Investigasi (root cause analysis) -> cari tahu yang jadi root problem (human error, teknis mesin)
3. korektif -> perbaikan langsung (validasi ulang, menghentikan penggunaan), perbaikan di next
4. pencegahan -> tindakan preventif agar tidak terulang -> revisi protab, pelatihan ulang ke personil
5. Monitoring & verifikasi -> memantau implementasi CAPA
-> dokumentasi dengan jelas di laporan audit, bersama bukti, lapor ke kepala bagian, invetasi -> CAPA
